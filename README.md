# 🚀 MyBlog - Modern Django Blogging Platform

A full-featured, responsive blogging web application built with **Django** and styled with **Tailwind CSS**. Designed with a clean UI, user authentication, dynamic category filtering, word count calculation, and robust post management.

[View Live Demo](https://blog2-one-green.vercel.app/) · [Report Bug](https://github.com/Raushankumarop/blog2/issues) · [Request Feature](https://github.com/Raushankumarop/blog2/issues)

</div>

---

## 📸 Features & Screenshots

* **Modern Tailwind UI:** Clean component-driven architecture with smooth layouts and mobile-first responsiveness.
* **Category Management:** Dynamic category feeds with real-time post counts, icons, and summaries.
* **Post Lifecycle:** Complete CRUD functionality (Create, Read, Update, Delete) with confirmation modals.
* **User Authentication:** Secure registration, login decorators (`@login_required`), and session handling.
* **Smart Metadata:** Automatic author assignment, publication status badges (Published/Draft), and dynamic word-count counters.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** Tailwind CSS, HTML5, Django Template Engine
* **Database:** SQLite
* **Authentication:** Django Auth & Form Handling
